# StudyAI 🧠

StudyAI is an AI-powered personalized study assistant built with Python, Streamlit, and Google Gemini.

## ✨ What it does

StudyAI turns your own study notes into personalized quizzes.

- 📝 Takes the student's subject and notes
- 🤖 Uses Google Gemini to generate questions
- ❓ Creates multiple-choice quizzes
- 🎚️ Supports Easy, Medium, and Hard difficulty
- ✅ Checks answers and explains mistakes
- 📊 Tracks the student's score
- 🧠 Adapts quiz difficulty based on performance
- 📚 Creates an AI-generated review of mistakes

## 🛠️ Technologies

- Python
- Streamlit
- Google Gemini API
- JSON
- GitHub

## 💡 Why I built it

I wanted to explore how artificial intelligence could be used to create a more personalized learning experience.

I started with very little programming experience and built StudyAI while learning Python, APIs, JSON, GitHub, and Streamlit.

## 🚀 How it works

1. Enter your name.
2. Enter the subject you are studying.
3. Add your study notes.
4. Choose a difficulty level.
5. StudyAI generates a personalized quiz.
6. Answer the multiple-choice questions.
7. StudyAI checks your answers and explains mistakes.
8. Receive an AI-generated review based on your mistakes.

## 🎯 Project Goal

The goal of StudyAI is to make studying more interactive and personalized by using AI to adapt questions and feedback to each student's learning material.

## 👩‍💻 Project

Built as a personal learning project while learning AI and Python development.
